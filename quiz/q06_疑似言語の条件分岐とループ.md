## アルゴリズム仕上げの10問クイズ

### 【問1】 条件分岐（if）の優先順位

ある数値 x が 95 のとき、以下のプログラムを実行すると何が表示されますか？


if (x ≧ 80)

    「良」を表示

elseif (x ≧ 90)

    「優」を表示

else

    「可」を表示

endif



A. 優
B. 良
C. 可
D. 何も表示されない

### 【問2】 複合条件（and）

if ( (a ＞ 10) and (b ＜ 5) ) という条件が「真」になる a と b の組み合わせはどれですか？
A. a ＝ 10, b ＝ 4
B. a ＝ 15, b ＝ 5
C. a ＝ 8, b ＝ 3
D. a ＝ 12, b ＝ 2

### 【問3】 二重ループの回転数

次のプログラムで、「★」は合計で何回表示されますか？


for (i を 1 から 3 まで 1 ずつ増やす)

    for (j を 1 から 2 まで 1 ずつ増やす)

        「★」を表示

    endfor

endfor



A. 3回
B. 5回
C. 6回
D. 9回

### 【問4】 ループ内での変数変化

次の処理が終わったとき、変数 sum の値は何になりますか？


sum ← 0

for (i を 1 から 3 まで 1 ずつ増やす)

    sum ← sum + i

endfor



A. 3
B. 5
C. 6
D. 10

### 【問5】 mod演算とifの組み合わせ

「数値 n が 3の倍数 である」ことを調べるための正しい条件式はどれですか？
A. n / 3 ＝ 0
B. n mod 3 ＝ 0
C. n mod 3 ＝ 3
D. n and 3 ＝ 0

### 【問6】 二次元配列のアクセス

整数型の二次元配列 mat[2, 2] の中身が {{10, 20}, {30, 40}} のとき、mat[2, 1] の値は何ですか？（添字は1から始まるとします）
A. 10
B. 20
C. 30
D. 40

### 【問7】 if-elseifの論理

以下のプログラムで、「要注意」 と表示される temp（気温）の値はどれですか？


if (temp ≧ 35)

    「危険」を表示

elseif (temp ≧ 30)

    「要注意」を表示

else

    「安全」を表示

endif



A. 29
B. 30
C. 35
D. 40

### 【問8】 二重ループと変数の値

次の処理を実行したとき、最後に表示される count の値は何ですか？


count ← 0

for (i を 1 から 2 まで 1 ずつ増やす)

    for (j を 1 から 2 まで 1 ずつ増やす)

        count ← count + i

    endfor

endfor



A. 4
B. 6
C. 2
D. 8

### 【問9】 andとorの混合

if ( (x ＞ 0) and ( (y ＝ 1) or (z ＝ 1) ) )

この条件が「真」になるケースとして、間違っているものはどれですか？
A. x＝1, y＝1, z＝0
B. x＝5, y＝0, z＝1
C. x＝10, y＝1, z＝1
D. x＝0, y＝1, z＝1

### 【問10】 returnの挙動

以下のプログラムに score ＝ 80 を渡したとき、返ってくる値（戻り値）は何ですか？


○ check(整数型: score)

if (score ≧ 70)

    return 1

endif

return 0



A. 0
B. 1
C. 70
D. 80

---

## 正解と解説

1. 正解：B
* 解説： xは95なので、最初の x ≧ 80 で「真」となり、「良」が表示されます。それ以降の elseif は評価されません。


2. 正解：D
* 解説： a ＞ 10 かつ b ＜ 5 を両方満たすのは、a=12, b=2 だけです。


3. 正解：C
* 解説： 外側3回 × 内側2回 ＝ 6回実行されます。


4. 正解：C
* 解説： 0 + 1 + 2 + 3 の計算が行われ、結果は6になります。


5. 正解：B
* 解説： modは余りを出す計算です。3で割った余りが0なら、それは3の倍数です。


6. 正解：C
* 解説： [2, 1] は「2行目の1列目」を指します。


7. 正解：B
* 解説： 30以上35未満の範囲が「要注意」となります。35以上は最初の if で「危険」になります。


8. 正解：B
* 解説： (i=1, j=1) → +1, (i=1, j=2) → +1, (i=2, j=1) → +2, (i=2, j=2) → +2。合計 1+1+2+2 = 6 です。


9. 正解：D
* 解説： x ＞ 0 が必須条件ですが、Dは x＝0 なので、その時点で全体が「偽」になります。


10. 正解：B
* 解説： 80は70以上なので、ifの中に入り return 1 が実行されます。そこでプログラムは終了します。
