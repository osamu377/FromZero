# アルゴリズム基礎 習得度確認クイズ

**【注意事項】**
*   擬似言語の配列要素番号は **1から始まる** ものとします。
*   「←」は代入を意味し、右辺の値を左辺の変数に格納します。

---

### 問1：条件分岐の論理（最大値の判定）
次のプログラムは、異なる三つの整数 `x`, `y`, `z` を引数で受け取り、そのうちの最大値を返す関数 `maximum` である。空欄に入る条件式として正しいものを解答群から選べ。

**〔プログラム〕**
*   整数型: `maximum`(整数型: `x`, 整数型: `y`, 整数型: `z`)
    *   if ( **【　空欄　】** )
        *   return `x`
    *   elseif (`y ＞ z`)
        *   return `y`
    *   else
        *   return `z`
    *   endif

**【解答群】**
ア `x ＞ y`
イ `x ＞ y and x ＞ z`
ウ `x ＞ y and y ＞ z`
エ `x ＞ z`

---

### 問2：反復処理と配列（偶数のカウント）
次のプログラムは、正の整数の配列 `data` の中から、**4の倍数**である要素の個数を数えて返すものである。空欄に入る適切な記述を解答群から選べ。

**〔プログラム〕**
*   整数型: `countMultiplesOf4`(整数型の配列: `data`)
    *   整数型: `count ← 0`, `i`
    *   for (`i` を 1 から `data`の要素数 まで 1 ずつ増やす)
        *   if ( **【　空欄　】** )
            *   `count ← count ＋ 1`
        *   endif
    *   endfor
    *   return `count`

**【解答群】**
ア `data[i] mod 4 が 0 と等しい`
イ `data[i] mod 4 が 1 と等しい`
ウ `i mod 4 が 0 と等しい`
エ `count mod 4 が 0 と等しい`

### 問3：データ構造（スタックの操作）
次のプログラムは、要素数4の配列 `stack` を用いて、スタックから値を取り出す関数 `pop` を実装したものである。空欄に入る正しい式を解答群から選べ。
ここで、`stackPos` は次に値を格納する位置を指す。

**〔プログラム〕**
*   大域: 整数型: `stackPos` // 初期値は現在格納されている要素の次の位置
*   整数型: `pop`()
    *   整数型: `popData ← 未定義の値`
    *   if (`stackPos ＞ 1`)
        *   `stackPos ←` **【　空欄　】**
        *   `popData ← stack[stackPos]`
        *   `stack[stackPos] ← 未定義の値`
    *   endif
    *   return `popData`

**【解答群】**
ア `stackPos ＋ 1`
イ `stackPos － 1`
ウ `stackPos`
エ `1`

### 問4：数値アルゴリズム（2進数から10進数への変換）
次のプログラムは、"0"と"1"から成る文字列 `binary` を符号なし2進数と解釈し、その整数値を返す関数である。空欄に入る適切な式を解答群から選べ。
（例：引数が "101" の場合、5 を返す）

**〔プログラム〕**
*   整数型: `convDecimal`(文字列型: `binary`)
    *   整数型: `i, length, result ← 0`
    *   `length ← binaryの文字数`
    *   for (`i` を 1 から `length` まで 1 ずつ増やす)
        *   `result ←` **【　空欄　】**
    *   endfor
    *   return `result`

**【解答群】**
ア `result ＋ int(binaryの i文字目の文字)`
イ `result × 2 ＋ int(binaryの i文字目の文字)`
ウ `result × 2 ＋ int(binaryの (length － i ＋ 1)文字目の文字)`

---

## 【解答と解説】

*   **問1：正解（イ）**
    `x` が最大値であるためには、`x` が `y` よりも大きく、かつ `x` が `z` よりも大きい必要があります。
*   **問2：正解（ア）**
    ある数が4の倍数かどうかを判定するには、その数を4で割った余り（`mod 4`）が0であるかを確認します。
*   **問3：正解（イ）**
    スタックからデータを取り出す（pop）ときは、現在指している空き位置（`stackPos`）を1つ戻してから、その位置にあるデータを取り出します。
*   **問4：正解（イ）**
    2進数を10進数にする際は、現在の合計値を2倍しながら、新しい桁の数字（0か1）を足していく処理を繰り返します。
