## 可変長配列



ご提示いただいた資料（令和5年度〜令和7年度の公開問題）の記述形式に基づき、「可変長配列（要素数が動的に変化する配列）」をテーマにした擬似言語の予想問題を3問作成しました。



資料のプログラム（令和5年度問1や令和7年度問4など）では、可変長配列は以下のルールで記述されています：

初期化：整数型の配列: result ← {} // 要素数0の配列,

要素の追加：resultの末尾 に iの値 を追加する,

要素番号：1から始まる,,

### 問1：条件に合う要素の抽出

次のプログラムは、整数型の配列 data を受け取り、その中から 10より大きい値だけ を抽出して、新しい配列として返す関数 filterGreater10 である。空欄に入る正しい答えを解答群の中から選べ。


〔プログラム〕

○整数型の配列: filterGreater10(整数型の配列: data)

    整数型の配列: result ← {}

    整数型: i

    for (i を 1 から dataの要素数 まで 1 ずつ増やす)

        if ( 【　空欄　】 )

            resultの末尾 に data[i] を追加する

        endif

    endfor

    return result



【解答群】

ア　data[i] ＞ 10

イ　i ＞ 10

ウ　resultの要素数 ＞ 10

エ　data[i] ≧ 10

### 問3：二つの配列の結合

次の関数 combineArrays は、二つの整数型の配列 arrayA と arrayB を受け取り、それらを一つの配列に結合して返す。ただし、arrayA の要素をすべて追加した後に、arrayB の要素を追加するものとする。空欄に入る記述として正しいものを選べ。



〔プログラム〕

○整数型の配列: combineArrays(整数型の配列: arrayA, 整数型の配列: arrayB)

    整数型の配列: combined ← {}

    整数型: i

    for (i を 1 から arrayAの要素数 まで 1 ずつ増やす)

        combinedの末尾 に arrayA[i] を追加する

    endfor

    for ( 【　空欄　】 )

        combinedの末尾 に arrayB[i] を追加する

    endfor

    return combined



【解答群】

ア　i を 1 から arrayAの要素数 まで 1 ずつ増やす

イ　i を arrayAの要素数 ＋ 1 から arrayBの要素数 まで 1 ずつ増やす

ウ　i を 1 から arrayBの要素数 まで 1 ずつ増やす

エ　i を 1 から (arrayAの要素数 ＋ arrayBの要素数) まで 1 ずつ増やす



---



### 【解答と解説】



問1：正解（ア）

    「10より大きい」という条件は data[i] ＞ 10 です。可変長配列 result に対して 末尾に追加 という操作を行うことで、条件に合うものだけを動的に蓄積できます,。

問2：正解（イ）

    特定の値を「削除」するアルゴリズムは、実務上「それ以外のものを新しい配列に追加する」という処理で実装されることが多いです。そのため、条件は 等しくない となります。また、追加するのは元の配列の要素 words[i] です。

問3：正解（ウ）

    二つ目のループでは、arrayB の中身を 1番目から順番に取り出す必要があるため、制御記述は i を 1 から arrayBの要素数 まで となります。combined 側は 末尾に追加 という命令によって、自動的に arrayA の後ろにデータが繋がっていきます。

### 問3：繰り返し処理の中での関数呼び出し

令和7年度問1や令和7年度問4の構造を参考に、ループ内で関数を呼び出し、その結果をカウントする問題です。



【問題】

次のプログラムにおいて、関数 countEven を引数 data = {1, 2, 3, 4, 5} で呼び出したとき、関数 isEven が true を返す回数として正しいものを解答群の中から選べ。ここで、配列の要素番号は1から始まる。


〔プログラム〕

〇整数型: countEven(整数型の配列: data)

    整数型: count ← 0, i

    for (i を 1 から dataの要素数 まで 1 ずつ増やす)

        if (isEven(data[i]) が true と等しい)

            count ← count ＋ 1

        endif

    endfor

    return count

〇論理型: isEven(整数型: val)

    if (val mod 2 が 0 と等しい)

        return true

    else

        return false

    endif



【解答群】

ア　1回

イ　2回

ウ　3回

エ　5回



---



### 【解答と解説】



問1：正解（イ）

    資料のルールでは、呼び出された手続の処理が終わると、呼び出し元の次の行に戻ります。

    1. main が "C" を出力。

    2. main が proc2 を呼び出す。

    3. proc2 が proc1 を呼び出し、"A" を出力。

    4. proc2 に戻り、"B" を出力。

    5. main に戻り、proc1 を呼び出して "A" を出力。

    したがって、「C, A, B, A」の順になります。



問2：正解（イ）

    1. calculate(3) が呼び出され、n に 3 が入ります。

    2. double(3) が呼び出され、戻り値として 6 (3 × 2) が返ります。

    3. result は 6 ＋ 5 で 11 となります。



問3：正解（イ）

    1. ループによって配列の要素（1, 2, 3, 4, 5）が順に isEven に渡されます。

    2. isEven は引数が偶数のときにのみ true を返します。

    3. 配列内の偶数は 2 と 4 の 2 つであるため、true が返される回数は 2 回となります。

### 問3：大域変数によるフラグ管理

### 問3：空の状態からのデータ取得

令和7年度問3の「スタックが空のときは未定義の値を返す」,という仕様を参考にした問題です。次のプログラムにおいて、手続 main を実行したときの出力結果として正しいものを選べ。



〔プログラム〕

〇整数型: getValue(整数型の配列: list, 整数型: pos)

    整数型: val ← 未定義の値

    if (pos ≦ listの要素数)

        val ← list[pos]

    endif

    return val

main()

    整数型の配列: nums ← {100, 200}

    getValue(nums, 3) の値を出力する



【解答群】

ア　0

イ　100

ウ　200

エ　未定義（または何も出力されない）



---



### 【解答と解説】



問1：正解（エ）

    資料にある「未定義の値」による初期化の例に基づいています。ループ内で値が代入されるのは i が 2 と 4 のとき（偶数）のみです。data は一度も代入が行われないため、初期状態のまま「未定義」となります。

問2：正解（ウ）

    資料の定義では、変数を「未定義」の状態にするには、「未定義の値」を代入する必要があります,,。令和7年度問3の pop 処理でも、取り出した後の要素に 未定義の値 を代入して削除を表現しています。

問3：正解（エ）

    関数 getValue は、引数 pos が配列の範囲外（この場合は3）のとき、if 文の中を通らず、初期値である 未定義の値 を返します。資料のスタックの問題でも、空の状態で pop した場合には「未定義の値」が返される仕組みになっています,。
