ご提示いただいた公開問題（令和5年度～令和7年度）の記述形式と、資料「S02連結リスト.pdf」の内容に基づき、連結リストに関する擬似言語の演習問題を5問作成しました。



連結リストは配列と異なり、「データ本体」と「次のノードを指すポインタ」を持つ「ノード」が鎖のようにつながった動的なデータ構造です,。以下の問題では、資料のルールに従い、リストの終端や空の状態を「未定義」または「未定義の値」と表現しています,,。



---



### 問1：リストの要素（ノード）の個数



次のプログラムは、連結リストの先頭ノードを指す head を受け取り、リストに含まれるノードの総数を返す関数 countNodes である。空欄に入れる正しい答えを選べ。



〔プログラム〕

〇整数型: countNodes(node_t: head)

    node_t: current ← head

    整数型: count ← 0

    while ( 【　空欄　】 )

        count ← count ＋ 1

        current ← current.next

    endwhile

    return count



【解答群】

ア　current が 未定義でない

イ　current.next が 未定義である

ウ　count ＜ 10

エ　current が 未定義である

### 問2：全要素の合計



次の関数 sumValues は、各ノードに整数が格納された連結リストを走査し、すべてのデータの合計値を算出する。空欄に入る適切な処理を選べ。


〔プログラム〕


〇整数型: sumValues(node_t: head)

    node_t: current ← head

    整数型: total ← 0

    while (current が 未定義でない)

        【　空欄　】

        current ← current.next

    endwhile

    return total



【解答群】

ア　total ← total ＋ current

イ　total ← current.val

ウ　total ← total ＋ current.val

エ　total ← total ＋ 1

### 問3：リストの先頭への挿入（Push）

次の手続 push は、新しい値 val を持つノードを作成し、リストの先頭に追加する処理である。空欄  a  、 b  に入る組み合わせとして正しいものを選べ。



〔プログラム〕

〇push(node_t: head, 整数型: val)

    node_t: newNode ← (新しいノードを作成しvalを設定したもの)

    newNode.next ← 【　a　】

    head ← 【　b　】



【解答群】

  a  b 

 :---  :---  :--- 

ア  【a】head  【b】newNode 

イ  【a】未定義の値  【b】newNode 

ウ  【a】newNode  【b】head 

エ  【a】head  【b】head.next

### 問4：リストの末尾ノードの特定

次のプログラムは、リストを辿って末尾（最後）のノードを見つけ、そのノードを返す処理の一部である,。空欄に入る適切な条件式を選べ。



〔プログラム〕

node_t: current ← head

if (current が 未定義でない)

    while ( 【　空欄　】 )

        current ← current.next

    endwhile

endif

return current



【解答群】

ア　current が 未定義でない

イ　current.next が 未定義でない

ウ　current.next が 未定義である

エ　current.val が 未定義でない



---



### 問5：リストの先頭要素の削除（Pop）

次の関数 pop は、リストの先頭ノードを削除し、そのノードが持っていた値を返す。空欄に入る適切な処理を選べ。



〔プログラム〕

〇整数型: pop(node_t: head)

    整数型: retval

    if (head が 未定義)

        return －1

    endif

    retval ← head.val

    【　空欄　】

    return retval



【解答群】

ア　head ← head.next

イ　head ← 未定義の値

ウ　head.next ← 未定義の値

エ　head.val ← 0

### 【解答と解説】



問1：正解（ア）

    資料にある探索（イテレーション）のアルゴリズムに基づき、作業用ポインタ current が 未定義（終端）になるまでループを繰り返します。

問2：正解（ウ）

    各ノードのデータ本体（val）にアクセスし、変数 total に加算していきます,。

問3：正解（ア）

    新しいノードの次（next）を現在の先頭（head）に向け、その後 head 自体を新しいノードに更新することで、先頭への挿入が完了します。

問4：正解（イ）

    「自分自身の次」が 未定義 であるノードが末尾です。したがって、「次がある間」ループを回すことで末尾で停止します,。

問5：正解（ア）

    先頭を削除するには、head ポインタを現在指しているノードの「次のノード」に書き換えます。
