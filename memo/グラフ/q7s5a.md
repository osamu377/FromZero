ご提示いただいた公開問題（令和5年度〜令和7年度）の記述形式と、資料「ch7s5グラフ.pdf」の内容に基づき、「ダイクストラ法（最短経路探索）」をテーマにした擬似言語の演習問題を5問作成しました。



ダイクストラ法は、「重み付きグラフ」においてスタート地点から各地点への最短距離を求めるアルゴリズムです,。資料にある「初期化」「探索」「更新（緩和）」のステップに基づいた構成にしています。



---



### 問1：初期化と最短距離の保持

次のプログラムは、ダイクストラ法を開始するための初期化処理の一部である。全5頂点のグラフにおいて、スタート地点 startNode（要素番号1〜5）から各頂点への暫定距離を格納する配列 dist を用意する。空欄に入る適切な記述を選べ。ここで、配列の要素番号は1から始まる。



〔プログラム〕

initialize(整数型: startNode)

    整数型の配列: dist ← {5個の 未定義の値}

    整数型: i

    for (i を 1 から 5 まで 1 ずつ増やす)

        if (i ＝ startNode)

            dist[i] ← 【　空欄　】

        else

            dist[i] ← 9999 // 十分に大きな値（無限大）とする

        endif

    endfor

    return dist



【解答群】

ア　0

イ　1

ウ　未定義の値

エ　-1

### 問2：未確定ノードからの選択（最小値の探索）

ダイクストラ法では、まだ「確定」していない地点の中から、最短距離が最も小さい地点を選んで「確定」とする。次のプログラムは、未確定の頂点の中から次に確定させる頂点の番号を返す関数の一部である。空欄に入る適切な条件式を選べ。



〔プログラム〕

整数型: findNextNode(整数型の配列: dist, 論理型の配列: isFixed)

    整数型: minDist ← 9999, nextNode ← －1, i

    for (i を 1 から distの要素数 まで 1 ずつ増やす)

        if (【　空欄　】)

            minDist ← dist[i]

            nextNode ← i

        endif

    endfor

    return nextNode



【解答群】

ア　isFixed[i] が true と等しい and dist[i] ＜ minDist

イ　isFixed[i] が false と等しい and dist[i] ＞ minDist

ウ　isFixed[i] が false と等しい and dist[i] ＜ minDist

エ　dist[i] ＝ 0

### 問3：距離の更新（緩和処理）

確定した地点 u から隣接する地点 v へ行くとき、現在の暫定距離よりも短くなる場合に値を書き換える処理を「更新（緩和）」と呼ぶ。空欄に入る適切な更新式を選べ。ここで、cost[u, v] は地点 u から v への移動コスト（重み）を表す。


〔プログラム〕

relax(整数型: u, 整数型: v, 整数型の配列: dist, 整数型の二次元配列: cost)

    整数型: newDist

    newDist ← dist[u] ＋ cost[u, v]

    if (newDist ＜ dist[v])

        【　空欄　】

    endif



【解答群】

ア　dist[u] ← newDist

イ　dist[v] ← newDist

ウ　dist[v] ← dist[u]

エ　cost[u, v] ← newDist

### 問4：アルゴリズムのトレース

資料にある「A駅からD駅までの最短時間」の例を考える。初期状態で A(0), B(∞), C(∞), D(∞) とし、Aを確定させた直後にB(10)とC(30)が更新されたとする。次に確定される駅名と、その直後の全駅の状態として正しいものはどれか。


【解答群】

ア　Cを確定する。状態は A:0(確), B:10, C:30(確), D:40 となる。

イ　Bを確定する。状態は A:0(確), B:10(確), C:30, D:60 となる。

ウ　Dを確定する。状態は A:0(確), B:10, C:30, D:40(確) となる。

エ　Bを確定する。状態は A:0(確), B:10(確), C:10, D:∞ となる。

### 問5：ダイクストラ法の制約

ダイクストラ法を正しく動作させるための重要な制約に関する問題である。次の記述のうち、正しいものはどれか。



【解答群】

ア　すべての辺のコストが「0以下」でなければならない。

イ　辺に方向がある「有向グラフ」には使用できない。

ウ　すべての辺のコストが「0以上」でなければならない。

エ　頂点同士が網目状につながった「グラフ構造」には使用できない。



---



### 【解答と解説】



問1：正解（ア）

    スタート地点からスタート地点への距離は 0 です。それ以外を大きな値（無限大）で初期化することで、後の「更新（緩和）」で正しい値が上書きされるようにします。

問2：正解（ウ）

    「まだ確定していない（isFixed が false）」かつ「保持している暫定距離の中で最小のもの」を探すのがルールです。

問3：正解（イ）

    「スタートから u までの確定距離」に「u から v へのコスト」を足したものが、現在 v に保持されている dist[v] より小さければ、dist[v] をその新しい値（newDist）で更新します。

問4：正解（イ）

    未確定（B:10, C:30, D:∞）の中で最小の B(10) を確定させます。その後、Bから行けるD(B経由で60)を更新します（Cはまだ確定のみで更新前）。

問5：正解（ウ）

    資料の制約にある通り、マイナスのコストがあると「一度確定した距離が後から短くなる」可能性が生じ、アルゴリズムが破綻するため、コストは0以上である必要があります,。
