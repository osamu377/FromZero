# ヒープの構築と再構築（ヒープ化）

## ヒープの構築

例として、[5, 2, 7, 3, 6, 1, 4] というバラバラに並んだ配列をツリーに追加して、「親が子より大きい」というルールにしたがって、ヒープを構築します。

* `5` をツリーに追加

![](img/MkHeap4.JPG)

<div style="page-break-before:always"></div>

* `2` を追加 → `2 < 5` なので、**安定** 

![](img/MkHeap5.JPG)

* `7` を追加 → `5 < 7` なので、**入れ替え** 

![](img/MkHeap6.JPG)

<div style="page-break-before:always"></div>

* 入れ替え後、親 > 子 のルールに従っているので、**安定**

![](img/MkHeap7.JPG)

* `3` を追加 → `2 < 3` なので、**入れ替え** 

![](img/MkHeap8.JPG)

<div style="page-break-before:always"></div>

* 入れ替え後、親 > 子 のルールに従っているので、**安定**

![](img/MkHeap9.JPG)

* `6` を追加 → `3 < 6` なので、**入れ替え** 

![](img/MkHeap10.JPG)

<div style="page-break-before:always"></div>

* 入れ替え後、親 > 子 のルールに従っているので、**安定**

![](img/MkHeap11.JPG)

![](img/MkHeap12.JPG)

* `4` を追加 → `4 < 5` なので、**安定**

## ヒープの再構築：ヒープ化 (Heapify)

データを削除（頂点を取り出す）したとき、ヒープは以下の手順で形を整えます。

1. **空いた頂点に、一番末尾（右下）の要素を持ってくる。**
2. **その要素を子と比較し、ルール違反（子が自分より大きい等）なら入れ替える。**
3. **これを適切な位置に収まるまで繰り返す（沈み込み）。**

これを使って、配列をソートすることができます（ヒープソート）。
