# アルゴリズムと擬似言語 演習問題（全10問）

### 問1：手続の呼出しと出力
次のプログラムにおいて、手続 `main` を呼び出すと、出力される文字列の順番として正しいものはどれか。

**〔プログラム〕**
* `procA()`
    * "X" を出力する
    * `procB()`
* `procB()`
    * "Y" を出力する
* `main()`
    * `procB()`
    * "Z" を出力する
    * `procA()`

**【解答群】**
ア　"Y", "Z", "X", "Y"
イ　"Y", "Z", "Y", "X"
ウ　"X", "Y", "Z", "Y"
エ　"Z", "Y", "X", "Y"

### 問2：条件分岐の記述順序（成績判定）
次のプログラムは、引数 `score`（点数）に応じて成績を返す関数である。95点の場合に正しく "S" を返すために、空欄に入る条件式の組み合わせとして正しいものを選べ。

**〔プログラム〕**
* 〇文字列型: `checkGrade`(整数型: `score`)
    * if ( **【 a 】** )
        * return "S"
    * elseif ( **【 b 】** )
        * return "A"
    * else
        * return "B"
    * endif

**【解答群】**
ア　a: `score ≧ 60`, b: `score ≧ 90`
イ　a: `score ≧ 90`, b: `score ≧ 60`
ウ　a: `score ＞ 60`, b: `score ＞ 95`
エ　a: `score ＝ 90`, b: `score ＝ 60`

### 問3：論理演算（最大値の判定）
次のプログラムは、三つの異なる整数 `a`, `b`, `c` の中から最大値を返す関数である。空欄に入る適切な条件式を選べ。

**〔プログラム〕**
* 〇整数型: `findMax`(整数型: `a`, 整数型: `b`, 整数型: `c`)
    * if ( **【 空欄 】** )
        * return `a`
    * elseif (`b ＞ c`)
        * return `b`
    * else
        * return `c`
    * endif

**【解答群】**
ア　`a ＞ b or a ＞ c`
イ　`a ＞ b and b ＞ c`
ウ　`a ＞ b and a ＞ c`
エ　`a ＞ c`

### 問4：配列の要素の合計
次のプログラムは、整数型の配列 `data` の全要素の合計を求めるものである。空欄に入る適切な記述を選べ。

**〔プログラム〕**
* 〇整数型: `sumArray`(整数型の配列: `data`)
    * 整数型: `total ← 0`, `i`
    * for (`i` を 1 から `dataの要素数` まで 1 ずつ増やす)
        * **【 空欄 】**
    * endfor
    * return `total`

**【解答群】**
ア　`total ← data[i]`
イ　`total ← total ＋ i`
ウ　`total ← total ＋ data[i]`
エ　`total ← data[total ＋ i]`

### 問5：データ構造（スタックのPush）
次のプログラムは、スタックに値を追加する関数 `push` である。空欄に入る適切な記述を選べ。ここで、`stackPos` は次に値を格納する位置を指す。

**〔プログラム〕**
* 大域: 整数型の配列: `stack`（要素数4）
* 大域: 整数型: `stackPos`（初期値1）
* 〇論理型: `push`(整数型: `inputData`)
    * if (`stackPos ≦ stackの要素数`)
        * `stack[` **【 a 】** `] ← inputData`
        * `stackPos ←` **【 b 】**
        * return true
    * endif
    * return false

**【解答群】**
ア　a: `stackPos`, b: `stackPos ＋ 1`
イ　a: `stackPos`, b: `stackPos － 1`
ウ　a: `stackPos － 1`, b: `stackPos ＋ 1`
エ　a: `stackPos ＋ 1`, b: `stackPos`

### 問6：2進数から10進数への変換
次のプログラムは、"0"と"1"のみからなる文字列 `binStr` を2進数とみなし、10進数の整数に変換するものである。空欄に入る式を選べ。

**〔プログラム〕**
* 〇整数型: `toDecimal`(文字列型: `binStr`)
    * 整数型: `i, res ← 0`
    * for (`i` を 1 から `binStrの文字数` まで 1 ずつ増やす)
        * `res ←` **【 空欄 】**
    * endfor
    * return `res`

**【解答群】**
ア　`res ＋ int(binStrのi文字目の文字)`
イ　`res × 2 ＋ int(binStrのi文字目の文字)`
ウ　`res × 10 ＋ int(binStrのi文字目の文字)`
エ　`res ＋ 2 ＋ int(binStrのi文字目の文字)`

### 問7：二重ループと二次元配列
次のプログラムを実行したとき、変数 `total` の値はどうなるか。

**〔プログラム〕**
* 整数型の二次元配列: `grid ← {{1, 2}, {3, 4}}` // 2行2列
* 整数型: `r, c, total ← 0`
* for (`r` を 1 から 2 まで 1 ずつ増やす)
    * for (`c` を 1 から 2 まで 1 ずつ増やす)
        * `total ← total ＋ grid[r, c]`
    * endfor
* endfor

**【解答群】**
ア　3
イ　6
ウ　10
エ　15

### 問8：文字列探索の比較回数
関数 `search` を `search("AAAAA", "AA")` として呼び出したとき、条件式「`data[i+j-1] が key[j] と等しい`」が真となる回数は何回か。

**〔プログラム〕**
* 〇整数型: `search`(文字型の配列: `data`, 文字型の配列: `key`)
    * for (`i` を 1 から `(dataの要素数 － keyの要素数 ＋ 1)` まで 1 ずつ増やす)
        * for (`j` を 1 から `keyの要素数` まで 1 ずつ増やす)
            * if (`data[i ＋ j － 1]` が `key[j]` と等しい)
                // 一致判定
            endif
        endfor
    endfor

**【解答群】**
ア　4回
イ　5回
ウ　8回
エ　10回

### 問9：倍数のカウントと余り計算
次のプログラムは、1から100までの整数のうち、3の倍数かつ5の倍数である数の個数を数えるものである。空欄に入る条件式を選べ。

**〔プログラム〕**
* 〇整数型: `countSpecials`()
    * 整数型: `i, count ← 0`
    * for (`i` を 1 から 100 まで 1 ずつ増やす)
        * if ( **【 空欄 】** )
            * `count ← count ＋ 1`
        * endif
    * endfor
    * return `count`

**【解答群】**
ア　`i mod 3 ＝ 0 or i mod 5 ＝ 0`
イ　`i mod 15 ＝ 0`
ウ　`i ÷ 15 ＝ 0`
エ　`i mod 3 ＝ 0 and i mod 5 ＝ 0`
※注：イとエは論理的に同値ですが、複合条件の練習としてエも正解の候補となります。

### 問10：ループの終了条件（余り計算の応用）
次のプログラムにおいて、12円を「1円、5円、10円」で支払う組み合わせを計算する際、`while` 文のループは何回実行されるか。

**〔プログラム〕**
* 〇整数型: `change`(整数型: `n`) // n = 12
    * `整数型: count ← 0, rest ← n`
    * while (`rest ≧ 0`)
        * `count ← count ＋ (rest ÷ 5 の商) ＋ 1`
        * `rest ← rest － 10`
    * endwhile
    * return `count`

**【解答群】**
ア　1回
イ　2回
ウ　3回
エ　4回

### 解答一覧
1. **ア**（procB→Z→procA(X→procB(Y)) の順）
2. **イ**（範囲の狭い条件から判定する）
3. **ウ**（aがbより大きく、かつaがcより大きい場合）
4. **ウ**（現在の合計に新しい要素を足して上書きする）
5. **ア**（現在位置に格納し、次に備えてインデックスを増やす）
6. **イ**（桁をずらすために2倍して次の位を足す）
7. **ウ**（1+2+3+4 = 10）
8. **ウ**（各開始位置で2回ずつ、合計4箇所で比較が成功する）
9. **エ**（またはイ。両方の条件を同時に満たす必要がある）
10. **イ**（12 ≧ 0 で1回、2 ≧ 0 で2回、-8 ≧ 0 で終了）
