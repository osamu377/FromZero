# 疑似コードでのクラスの書き方

## IPA 試験向けの「最適な class 疑似コード」はこれ

### 一般的な書き方

```text
class クラス名
    public 属性名1
    private 属性名2

    constructor(引数…)
        this.属性名1 ← 初期値
        this.属性名2 ← 初期値
    end constructor

    method メソッド名(引数…)
        処理…
        return 戻り値
    end method
end class
```

### 例 Userクラス

```text
class User
    public name
    private age

    constructor(name, age)
        this.name ← name
        this.age  ← age
    end constructor

    method greet()
        output "Hello, I am " + this.name
    end method
end class
```

### PublicとPrivateの違い

インスタンス外部からアクセスできるかどうか？

`private` キーワードがついた変数は、外部から読み取ることも代入することもできない。

ただし、内部のメソッドからはアクセス可能。

そのため、必要に応じて、外部から読み出しできるメソッドや代入できるメソッド(`getter`、`setter`と呼ばれることがある)を定義することで対応する。

```text
method setName(文字列型 name)
    this.name ← name
end method
```

`public` キーワードがつくと、インスタンスの外から自由にアクセスできる。
