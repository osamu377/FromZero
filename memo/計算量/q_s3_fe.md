# 線形探索・二分探索 演習問題

### 問1：線形探索の基本アルゴリズム

次の関数 `linearSearch` は、整数型の配列 `data` から引数 `target` と一致する要素を先頭から順に探し、見つかった場合はその要素番号を、見つからない場合は －1 を返す。空欄に入る適切な条件式を選べ。

〔プログラム〕
〇整数型: `linearSearch`(整数型の配列: `data`, 整数型: `target`)
    整数型: `i`
    for (`i` を 1 から `dataの要素数` まで 1 ずつ増やす)
        if ( 【　空欄　】 )
            return `i`
        endif
    endfor
    return －1

【解答群】
ア　`data[i] が target と等しい`
イ　`i が target と等しい`
ウ　`data[i] が 未定義の値 と等しい`
エ　`target が dataの要素数 と等しい`

### 問2：二分探索の範囲更新
次の関数 `binarySearch` は、昇順に整列された整数型の配列 `data` から `target` を探す。中央の値と `target` を比較し、`target` の方が大きい場合に、次に探索する範囲（下限 `low`）を更新する正しい処理はどれか。

〔プログラム〕
〇整数型: `binarySearch`(整数型の配列: `data`, 整数型: `target`)
    整数型: `low ← 1`, `high ← dataの要素数`, `middle`
    while (`low ≦ high`)
        `middle ← (low ＋ high) ÷ 2 の商`
        if (`data[middle] ＝ target`)
            return `middle`
        elseif (`data[middle] ＜ target`)
            【　空欄　】
        else
            `high ← middle － 1`
        endif
    endwhile
    return －1

【解答群】
ア　`low ← middle`
イ　`low ← middle ＋ 1`
ウ　`low ← high ＋ 1`
エ　`low ← 1`

### 問3：二分探索の計算量（ステップ数）
資料「S03_探索と計算量.pdf」によると、要素数が 1,024 個の整列済みリストに対して二分探索を行った場合、最悪（ターゲットが最後に見つかるか見つからない場合）でも最大何回の比較（ステップ）で終了するか。

【解答群】
ア　7回
イ　10回
ウ　32回
エ　1,024回

### 問4：探索アルゴリズムの比較
次の記述のうち、線形探索と二分探索の特徴を比較したものとして正しいものはどれか。

【解答群】
ア　線形探索はデータが整列されている必要があるが、二分探索はその必要がない。
イ　データ数が 40億個ある場合、線形探索の最悪ステップ数は 40億回だが、二分探索は約32回である。
ウ　二分探索の時間計算量は $O(n)$ であり、線形探索の $O(\log n)$ よりも高速である。
エ　線形探索は常に中央の要素からチェックを開始する。

### 問5：計算量オーダーの判定
「入力サイズ $n$ が 2倍、3倍と増えるに従って、処理ステップ数も同じく 2倍、3倍と直線的に増えていく」ようなアルゴリズムの計算量を表すオーダー記法（$O$ 記法）はどれか。

【解答群】
ア　$O(1)$
イ　$O(\log n)$
ウ　$O(n)$
エ　$O(n^2)$

---

## 【解答と解説】

1.  正解：ア
    *   解説：線形探索は「すべての数字を一列に並んでいるかのように」一つずつ比較するため、配列の各要素 `data[i]` が探している値 `target` と一致するかを判定します。要素番号は 1 から始まります。
2.  正解：イ
    *   解説：二分探索で中央の値よりターゲットが大きい場合、中央より左側には答えがないことが分かります。そのため、下限 `low` を `middle + 1` にずらすことで、探索範囲を半分に絞り込みます。
3.  正解：イ
    *   解説：$2^{10} = 1024$ であるため、$\log_2 1024 = 10$ となり、最大10ステップで終了します。
4.  正解：イ
    *   解説：線形探索の計算時間はリストのサイズ $n$ に比例する「線形時間」ですが、二分探索は「対数時間」であり、要素数が増えるほど二つの時間の差は圧倒的に大きくなります。
5.  正解：ウ
    *   解説：データ数に比例して処理時間が増加するものを「線形時間 $O(n)$」と呼びます。
